# **App Name**: SmartCalm Reports

## Core Features:

- Student Daily Report Form: Digital form for students to record daily activities, study hours, sleep, and personal evaluations.  Includes smart time selection, file attachments and is available for offline use.
- Personal Stats Dashboard: A dashboard providing students with personal stats through calm, aesthetically pleasing charts displaying study habits and progress. Includes automatically generated motivation tips based on trend analysis.
- Teacher Analytics Dashboard: Provides teachers with aggregate and individual student data, visualized through charts for performance analysis and trend identification.
- Automated Alert System: Analyzes student inputs to identify decreasing motivation or declining performance, providing proactive alerts and recommendations to teachers and students. It can use a tool for recommending incentives to be included in its alerts.
- Account Management: Allows teachers to manage student accounts, classes, and send personalized messages to individual students. The system handles account access securely.
- Data Export: Enables teachers and admins to export reports and charts in Excel or PDF format for meetings and analysis.
- Offline Data Sync: Allows students to fill out reports offline, which are then synced when the connection is re-established, combining local storage with a cloud database such as Supabase or Firebase.

## Style Guidelines:

- Background color: Very light silver (#F0F4F7) to ensure calm, neutral feeling.
- Primary color: Soft turquoise (#74BCC6) promoting a sense of intelligence.
- Accent color: Dusty blue (#8AA2A8) providing calm, cool highlights.
- Body font: 'Vazirmatn', a calm sans-serif font, suitable for user interfaces.
- Headline font: 'YekanBakh', a bold sans-serif to create a sense of hierarchy
- Minimalist design with generous spacing for a less crowded feel and more focus. Features calm UI and spatial layout principles.
- Subtle fade-in animations and smooth transitions throughout the user interface.
